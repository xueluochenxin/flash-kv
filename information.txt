 统一协议 
 * SET key value //OK  WRONG    key已经存在就去修改value
 * GET key       //value INEXIST
 * DEL key       //OK    INEXIST
 * MOD key value //OK    INEXIST
 * EXIST key     //YES   NO
 写：  SETB <key> <vlen>\n
       <vlen 字节原始内容>
        → OK\n        （成功）
        → INVALID\n   （头部语法错，或正文里含 '\0'）

读：  GETB <key>\n
        → <vlen>\n<vlen 字节原始内容>
        → INEXIST\n
